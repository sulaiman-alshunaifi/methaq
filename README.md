# ميثاق — منصة حوكمة وإدارة الأصول التقنية

منصة ويب عربية لعرض وتحليل سجل الأصول التقنية، وقياس الالتزام بالضوابط الأساسية للأمن السيبراني (ECC-2:2024) الصادرة عن الهيئة الوطنية للأمن السيبراني.

**رابط المنصة:** https://sulaiman-alshunaifi.github.io/methaq/

## طريقة الاستخدام
1. افتح رابط المنصة (يلزم اتصال بالإنترنت).
2. اضغط **رفع ملف سجل الأصول** واختر ملف Excel بنفس هيكل الملف التجريبي.
3. تُحسب المؤشرات والرسوم والتقارير في كل الصفحات تلقائياً.

## محتويات المستودع
| الملف | الوصف |
|---|---|
| `index.html` | المنصة كاملة في ملف واحد |
| `sample/Tuwaiq_IT_Asset_Register_Demo.xlsx` | ملف بيانات وهمية للتجربة (1,200 أصل) |
| `docs/Mithaq_Guide_AR.docx` | دليل تعريفي بالمنصة |

## الخصوصية
- ملف Excel يُقرأ داخل متصفحك فقط، ولا يُرفع إلى أي خادم ولا إلى هذا المستودع.
- البيانات لا تُحفظ بعد إغلاق الصفحة.
- جميع البيانات في الملف التجريبي وهمية.
- **لا ترفع ملفات أصول حقيقية إلى هذا المستودع.**

## التقنيات
React · Tailwind CSS · Recharts · SheetJS · Lucide — تعمل كصفحة ثابتة بدون خادم.
